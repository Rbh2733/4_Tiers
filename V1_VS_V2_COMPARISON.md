## 🔢 Formula Changes Reference

### Position Sizing

**v1.0:**
```excel
= (Base% × Score/100) / (1 + (Beta-1) × Vol_Factor)

Example (Tier 2, Score 85, Beta 1.5):
= (7% × 0.85) / (1 + (0.5 × 1.0))
= 5.95% / 1.5
= 4.0%
```

**v2.0:**
```excel
Beta_Adj = 1 + (Beta-1) × Vol_Factor
DD_Penalty = 1 + (MaxDD% / 100) × 0.5
Combined_Risk = Beta_Adj × DD_Penalty

Position = (Base% × Score/100) / Combined_Risk

Example (Tier 2, Score 85, Beta 1.5, Max DD -30%):
Beta_Adj = 1.5
DD_Penalty = 1.15
Combined = 1.725

= (7% × 0.85) / 1.725
= 3.4% (vs 4.0% in v1.0 = 15% smaller)
```

---

### Composite Score

**v1.0:**
```excel
COMPOSITE = Valuation + Quality + Growth + Momentum + Other
(Single score, no adjustments)
```

**v2.0:**
```excel
RAW COMPOSITE = Valuation + Quality + Growth + Momentum + Other
ADJUSTED COMPOSITE = Raw + Sector_Adj + Cycle_Adj

Rating based on Adjusted Composite
Position sizing based on Adjusted Composite
```

## 💡 Pro Tips for v2.0

### 1. Don't Over-Adjust
- Sector adjustments are meant to be subtle (+/-2 max)
- If unsure, set sector/cycle adjustments to 0
- Over-adjustment defeats the purpose

### 2. Enforce Bonus Caps Strictly
- The caps are critical to v2.0's integrity
- When in doubt, round down
- Document your bonus selections in Notes

### 3. Take Concentration Seriously
- New penalties are harsh by design
- If >30% from one customer, score WILL suffer
- Consider this an exit warning

### 4. Monitor Burn Rates Actively
- Quarterly burn rate calculations
- 20%+ acceleration triggers immediate penalty
- Don't wait for quarter-end surprises

### 5. Set Stop Alerts Immediately
- Non-negotiable for v2.0
- Use your broker's price alert feature
- Review/adjust after stock splits or special dividends

### 6. Gather Max Drawdown Data
- Use Yahoo Finance / TradingView
- Calculate from your entry date forward
- Update quarterly as new data available

## ❓ FAQ

### Q: Can I still use v1.0 templates?
**A:** Yes for reference, but not for active decisions. v2.0 is superior for risk management and accuracy.

### Q: Will my scores be lower in v2.0?
**A:** Generally yes, by 2-9 points depending on tier and company characteristics. This is expected and beneficial.

### Q: What if my holding drops below the tier minimum in v2.0?
**A:** Begin 2-quarter watch. If it stays below for 2 consecutive quarters, exit. If stop loss hit first, exit immediately.

### Q: Do I need to use sector/cycle adjustments?
**A:** No, they're optional. Set to 0 if uncertain. But they add value if you have informed views.

### Q: Is Max Drawdown input required?
**A:** No, but highly recommended. If omitted, system defaults to beta-only sizing (v1.0 method).

### Q: Can I mix v1.0 and v2.0 for different tiers?
**A:** Not recommended. Use v2.0 across all tiers for consistency and risk management.
